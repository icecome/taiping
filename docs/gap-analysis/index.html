        /posts/lightweight-blog-on-workers

        把博客压到 Cloudflare Workers 上，最重要的不是功能堆叠，而是把「写」这件事留住。

        太平的控制台设计，希望更接近笔记软件：侧栏安静、正文宽敞、操作不抢焦点。发布只是写作的最后一步，而不是主流程。

        为什么是 Workers

        边缘运行时带来更低的冷启动与更简单的部署面。D1 负责关系数据，KV 缓存热点页面，R2 托管附件。状态外置之后，Worker 本身可以保持薄。

        轻量不是功能少，而是每一步都刚好够用。

        下一步可以把编辑器进一步做成 Notion 式的块编辑，但在预览阶段，先保留 Markdown 原文与安静的纸面排版。
